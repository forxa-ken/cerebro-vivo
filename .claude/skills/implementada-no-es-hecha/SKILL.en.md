# Implemented is not done

## How (steps)
1. "Implemented" = programmed and with tests; "done" = Darwin tested it.
2. Until the test, it stays in "Waiting for your test" with the concrete steps.
3. Say in the message which test is missing and what it consists of.
4. Do not push to GitHub before his confirmation, unless expressly ordered.

## Error it prevents (real case)
- Tasks were called done without the owner testing them and then failed (e.g. the manual's language in #68).
