# Traspaso entre chats

## Cómo (pasos)
1. Escribir `.brain/traspaso.md` con la plantilla (`biblioteca/PLANTILLA_TRASPASO.md`): palabras literales de Darwin, decisiones, estado de cada punto, lo no subido, lo descartado.
2. Después dar la frase corta para pegar o abrir el chat nuevo.
3. El arranque del chat nuevo lo muestra y lo archiva en `archive/traspasos/`.
4. Hacerlo pronto: la IA solo puede resumir lo que aún tiene en contexto.

## Error que evita (caso real)
- Al abrir un chat nuevo se perdía el último tramo hablado.
