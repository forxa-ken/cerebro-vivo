# State summary

## How (steps)
1. Read only, write nothing. Read `.brain/pendientes.md` and the last line of `.brain/decisions.log`; if `.brain/traspaso.md` exists, look at its section 3.
2. Tell it in 4-5 plain bullets, without jargon: version or state, what is missing (with their numbers), what is unpushed or uncommitted, what Darwin must test.
3. End with a single question: where to go next. Start nothing.

## Error it prevents (real case)
- Mixing the summary with starting work or with writing a handoff: it spends tokens and does what Darwin did not ask for.
