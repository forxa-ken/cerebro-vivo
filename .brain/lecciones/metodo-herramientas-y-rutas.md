# Lecciones: metodo-herramientas-y-rutas

Formato: problema → causa → regla. Las escribe `lecciones.py` en el momento del hito (spec 026).

- **Edge headless desde Bash no creó el PDF y no dio error** → la salida se perdió con el pipe y la ruta con espacios → **usar PowerShell Start-Process -Wait con --headless=new y --print-to-pdf entre comillas, y comprobar que el archivo existe** (2026-11-11)
- **gh run watch observó el run anterior ya terminado, no el nuevo** → tomé el último run de la lista antes de que GitHub registrara el push → **esperar unos segundos y comprobar que headSha del run coincide con el commit subido** (2026-11-11)
- **Edit sobre datos.js de la carpeta de la página falló con 'File has not been read yet'** → el archivo era de otra carpeta (_cv_pagina) y yo solo lo había mirado con sed/grep por Bash, no con Read → **antes de Edit en un archivo, leerlo con Read aunque ya se haya visto con grep; lanzar el Read y el Edit en mensajes distintos** (2026-11-12)
- **Tres ediciones a la vez fallaron en la carpeta de la pagina (_cv_pagina)** → la herramienta Edit exige haber leido el archivo en este chat y yo lance las ediciones sin leerlo → **antes de editar archivos de otra carpeta (la pagina publica) leer con Read la linea exacta; las tres ediciones se lanzan juntas solo despues de leerlas** (2026-11-14)
- **Al instalar Go con winget en modo silencioso el comando quedó colgado más de 400 s sin salida y Go no apareció** → winget pide el permiso de administrador de Windows en una ventana que puede quedar oculta, y en segundo plano nadie la ve ni la acepta → **antes de instalar con winget avisar a Darwin de que aparecerá la ventana de permiso, lanzar el comando en segundo plano con un límite de espera corto y, si no hay avance, preguntarle por la ventana en lugar de seguir esperando** (2026-11-14)
- **go install de vcsim con arroba latest falló por un replace en su go.mod, y en pyvmomi la propiedad snapshot de una máquina no existe cuando no hay instantáneas y rompió la exploración** → go install no admite módulos con directivas replace, y pyvmomi no define los atributos vacíos de los objetos → **para herramientas de Go con replace clonar el repositorio y compilar con go build desde su carpeta; con pyvmomi leer atributos opcionales con getattr y un valor por defecto** (2026-11-14)
- **Edit falló con File has not been read yet al editar el AGENTS.md de otra carpeta del experimento, y las demás llamadas del mismo mensaje siguieron sin él** → la herramienta Edit exige haber leído el archivo antes en la conversación, y yo lo había visto solo con sed desde Bash, que no cuenta → **antes de editar un archivo que solo se ha mirado por la terminal, leerlo con la herramienta Read, y no lanzar en el mismo mensaje otras llamadas que dependan de que esa edición salga bien** (2026-11-14)
