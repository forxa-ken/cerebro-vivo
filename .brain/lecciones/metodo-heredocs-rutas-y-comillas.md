# Lecciones: metodo-heredocs-rutas-y-comillas

Formato: problema → causa → regla. Las escribe `lecciones.py` en el momento del hito (spec 026).

- **En pendientes.md una ruta de Windows quedó con un carácter raro (F:\Proyectos Antigravitymware...)** → escribí la ruta F:\Proyectos Antigravity\vmware dentro de una cadena de Python normal y \v es el salto vertical, así que se comió la v; además la corrección con replace('\v') no coincidió y hizo falta repetirla → **al escribir rutas de Windows desde Python o heredocs, usar cadenas crudas r"..." o chr(92), y comprobar con grep o repr que la línea quedó bien antes de dar el cambio por hecho** (2026-11-09)
- **Un bloque bash con varios heredocs y comillas mezcladas (python -c y textos con comillas simples y «») falló entero con 'unexpected EOF' y no escribió nada** → bash analiza el comando completo antes de ejecutarlo y una comilla simple suelta rompe todo, aunque los heredocs lleven comilla → **para archivos con comillas o acentos usar la herramienta Write (o un .py escrito con Write y ejecutado aparte), no heredocs largos; comprobar siempre que el archivo existe tras un error** (2026-11-12)
- **Un script Python en heredoc buscó un texto con tildes (válido) y su assert falló aunque el texto estaba en el archivo** → en Git Bash de Windows el heredoc pasa las tildes con otra codificación, así que la cadena no coincide → **para editar texto con tildes usar la herramienta Edit (regla 10), no un heredoc; si hay que usar script, escribir las tildes como \u00e1 o leer el archivo y comprobar antes con assert** (2026-11-13)
