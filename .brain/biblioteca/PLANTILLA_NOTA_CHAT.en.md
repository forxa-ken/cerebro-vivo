# Template for a helper chat's note (spec 080)

A chat that came out of another (forked or helper) writes this **when it finishes its task**, in `.brain/notas-chats/YYYY-MM-DD-HHMM-<name>.md`. The next main chat that starts shows it and archives it in `.brain/archive/notas-chats/`. It does not go to GitHub. About 10 lines.

```markdown
# Note from <chat name> (YYYY-MM-DD)
- Task: …
- Done: … (files touched)
- Untested / unpushed: …
- Decisions or doubts for the main chat: …
```
