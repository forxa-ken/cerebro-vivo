# Hallazgos compartidos (plantilla; spec 043)

Copia este archivo a `.brain/hallazgos-compartidos.md`. Regla única: **antes de investigar algo, mira el de los proyectos hermanos; tras investigar algo útil para varios, anótalo aquí**. Una entrada por hallazgo, más reciente arriba. Solo lo que sirve a otros proyectos; el detalle largo se enlaza, no se pega.
