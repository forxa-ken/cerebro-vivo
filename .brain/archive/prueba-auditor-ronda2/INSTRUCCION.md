# Instrucción para el auditor (igual para los tres)

Eres un auditor independiente. Revisa SOLO lectura el proyecto en `proyecto/` (código, `tests/` y `REQUISITOS.md`): no lo modifiques. Puedes ejecutar comprobaciones (`python`) para confirmar cosas, sin escribir en el proyecto.
Busca fallos de **calidad** (el código no cumple lo que dicen los requisitos, errores de lógica, pruebas que no protegen), de **consumo** de recursos y de **seguridad**. Cruza el código con `REQUISITOS.md`.
Para cada hallazgo da: archivo y función, qué falla, gravedad (alta/media/baja), y si lo comprobaste ejecutándolo. No inventes fallos: si dudas, dilo. Termina con una lista numerada.
Modo: revisión general, esfuerzo medio.
